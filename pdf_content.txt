Les données en détail : Les attributs de aicraftTypes
AircraftDescription : description générale (LandPlane).
Description : informations descriptives complémentaires sur le modèle
d’avion (L2J).
Designator : code de désignation normalisé de l’aéronef (OACI : J328).
EngineCount : nombre de moteurs équipant l’aéronef (ex 2).
EngineType : type de motorisation utilisé (ex jet).
ManufacturerCode : code identifiant le constructeur de l’aéronef (328
SUPPORT SERVICES).
ModelFullName : nom complet du modèle de l’aéronef (Dornier 328JET).
WTC: catégorie de turbulence de sillage ( Wake Turbulence Category )
associée à l’aéronef avec : Light (léger) M:Medium (moyen) H:Heavy
(lourd) J:Super (très gros porteur, ex. Airbus A380)

Les données en détail : Les attributs de flightsample
icao24 : identifiant unique de l’aéronef codé en hexadécimal (a1226b).
firstseen : horodatage Unix correspondant à la première détection du vol
par le réseau (1662034693.0 horodatage Unix exprimé en secondes écoulées depuis le 1erjanvier 1970 à 00 :00 :00
UTC. Ici, 1erseptembre 2022 à 13 :24 :53 UTC )
takeofftime : heure de décollage de l’aéronef (horodatage Unix).
lastseen : horodatage Unix de la dernière détection du vol.
landingtime : heure estimée d’atterrissage (horodatage Unix).
callsign : indicatif radio. UPS312 désigne la compagnie UPS.
estdepartureairport : code OACI de l’aéroport de départ estimé. KSAT
correspond à l’aéroport international de San Antonio.
airportofdeparture : aéroport de départ confirmé (code OACI).
estarrivalairport : code OACI de l’aéroport d’arrivée estimé.
airportofdestination : aéroport d’arrivée confirmé.
model : nom du modèle de l’aéronef. A300 F4-622R Airbus A300.
typecode : code OACI du type d’aéronef. A306 un Airbus A300-600.
registration : immatriculation officielle de l’aéronef. ( N172UP )

Les données en détail : Les attributs de airbustree
time : horodatage Unix correspondant au moment de l’enregistrement des
données de position. 1513165649 correspond au 13 décembre 2017 à
11 :20 :49 UTC.
icao24 : identifiant unique de l’aéronef codé en hexadécimal.
lat: latitude de l’aéronef en degrés décimaux.
lon: longitude de l’aéronef en degrés décimaux.
velocity : vitesse horizontale de l’aéronef en mètres par seconde. 65.24
m/s correspond à environ 235 km/h.
heading : cap de l’aéronef en degrés par rapport au nord géographique.
232.05 indique une direction sud-ouest.
vertrate : vitesse verticale en mètres par seconde. 8.77824 signifie que
l’avion monte à environ 8.8 m/s.
callsign : identifiant opérationnel ou indicatif radio du vol.
onground : indique si l’aéronef est au sol ( true ) ou en vol ( false ).
alert : indicateur d’alerte transmis par le transpondeur. false signifie
qu’aucune alerte n’est active.

Les données en détail : Les attributs de airbustree
spi: indicateur Special Position Identification utilisé lors d’une identification

1513165648.765 indique le dernier contact enregistré.
hour : horodatage Unix correspondant au début de l’heure de collecte des
données. 1513162800 correspond au 13 décembre 2017 à 11 :00 :00 UTC.

Exemple
Relation AircraftTypes
AircraftTypes(AircraftDescription, Description, Designator, EngineCount,
EngineType, ManufacturerCode, ModelFullName, WTC)
Dépendance fonctionnelle :
{Designator }→{AircraftDescription ,Description ,EngineCount ,
EngineType ,ManufacturerCode ,ModelFullName ,WTC}
Clé candidate : {Designator }
Les étudiants auront en plus à justifier
Relation flightSample
flightSample(icao24, firstseen, takeofftime, lastseen, landingtime, callsign,
registration, model, typecode, estdepartureairport, airportofdeparture,
estarrivalairport, airportofdestination)
Dépendances fonctionnelles :
{registration }→{model ,typecode }
{model}→{typecode }Clé candidate : {registration }
